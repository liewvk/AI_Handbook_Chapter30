# AI Handbook — Chapter 30

This repository contains the Python examples for **Chapter 30** of the AI Handbook. It demonstrates practical concepts for evaluating AI responses, recording learning progress, and assessing project readiness.

## Examples

| File | Description |
| --- | --- |
| [`example30.2.py`](example30.2.py) | Calculates a pass/total completion rate from a set of test cases and identifies failures that need improvement. |
| [`example30.3.py`](example30.3.py) | Writes a structured learning journal entry to `ai_learning_journal.csv` using Python's `csv` module. |
| [`example30.4.py`](example30.4.py) | Checks readiness criteria and reports items that still require action. |
| [`ai_learning_journal.csv`](ai_learning_journal.csv) | Stores a learning journal entry generated by the Chapter 30 example. |

## Requirements

- Python 3

No third-party packages are required.

## Running the examples

From the repository root, run:

```bash
python example30.2.py
python example30.3.py
python example30.4.py
```

Running `example30.3.py` replaces `ai_learning_journal.csv` with a new, single-entry learning journal.
